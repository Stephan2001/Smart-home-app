
# UnoHome App

## Purpose of the App
UnoHome is a Kotlin-based smart home application used for Android devices that allows users to manage specific smart home devices through the use of their phones. UnoHome users are able to manage their smart home devices through the use of a variety of features. These features include having the option to control each indivudal device, having the ability to create personalised themes which adjust multiple devices to set the desired ambiance for your home and allows users to create specific automated routines for seemless home management and scheduling. Not only can a user manage their devices but can also view active real-time sensor readings on the UnoHome Dashboard along with sensor reading hisotry and a history of user actions.

## Release Notes

Since the development of the prototype, a few additions and functionalities have been added to the UnoHome smart home application:

**Offline syncing:**
   - Users can now still make use of the application while offline / not connected to the internet. While offline, a user is still able to add devices to their profile, create themes, create routines, turn devices on and turn devices off. Once the user has regained internet connection, all actions conducted while offline will sync and be as if they were never offline.


**Biometric Login:**
   - Biometic authentication has now been included in the application! Users are now able to log into the app just by using their fingerprint as a form of authentication.


**Multi-Language Support:**
   - Multi-language support is now available in the application and allows the user to choose their language preference between English OR Afrikaans


**Sensor Readings:**
   - Introducing real-time sensor readings! UnoHome now has a Dashboard added, allowing the user to view the latest sensor reading recorded on the smart home. If the sensor reading is at a safe/normal level, it will be indicated in green text but if the sensor reading is above a safe/normal level it will indicate this in red text.

**Sensor History & User Logs:**
   - On the newly added dashboard, users are now also able to view a history of readings recorded by a sensor on the smart home. If a user clicks on the sensor device name, it will pop up with a history of previously recorded readings. With addition to the sensor history, users are now also able to view logs of all activies performed, whether it be creating a theme, turning a device off etc.


**Panic Alarm Functionality:**
   - On the newly added dashboard, users are now able to activate the panic alarm via the app and not just on the smart home! A panic button has been added to UnoHome's dashboard where if the user holds in the button for 3 seconds, the panic alarm will be activated on the smart home.

# Keystudio Smart Home Kit

## Overview
The Keystudio Smart Home Kit is an Arduino-based project that makes use of sensors/devices used to automate a home.

## Features
- **Motion Detection:** When motion is detected, a buzzer will go off
- **Light Management:** Lights can be turned on and off remotely from an application. With the use of the light sensor, lights will turn off when there is sufficient light and will turn on when there is insufficient light
- **Alarm System:** Involves a panic button that activates an alarm which will flash lights emit an alarm sound.
- **Remote Control:** All devices can  be controlled remotely using an application
- **Door and Window Control:** Servos devices are included that can be activated/deactivated to open or close doors and windows.
- **Fan Management:** The fan can be remotely activated to turn on/off.
- **LCD Screen:** The LCD screen confirms the house is active and displays panic alarm activation
- **Gas Sensor:** The Gas sensor detects gas in the area
- **Steam Sensor:** The steam sensor monitors moisture and smoke
- **Soil Sensor:** The soil sensor monitors for soil moisture/water levels

## Components
- **Sensors:**
  - Photocell Light Sensor
  - PIR Motion Sensor
  - MQ-2 Gas Sensor
  - Soil/Moisture Sensor
  - Steam Sensor
- **Actuators:**
  - Servo Motors
  - Passive Buzzer
  - LEDs
  - Relay Module
- **Buttons:** Manual controls and panic alarm activation
- **LCD Display:** Displays status messages

## Setting up the Smart Home
1. **Hardware Setup:**
   - Connect the devices/sensors to the Arduino Sensor Shield as per pin configuration
   - Ensure all devices/sensors are powered.

2. **Software Setup:**
   - Install the Arduino IDE (https://www.arduino.cc/en/software).
   - Install the following libraries:
     - Servo
     - LiquidCrystal_I2C
     - WiFiEsp
     - WiFiEspClient
     - WiFiEspServer
     - SPI
   - Upload the code to the Arduino board.

3. **Netowrk Setup:**
   - In the Arduino Code, define your routers SSID and password to connect for internet access:
   ```
   char ssid[] = "YourSSID";
   char password[] = "YourPassword";
   ```

void checkDeviceStatus() {
  if (!client.connected()) {  // Only connect if the client is not already connected
    Serial.print("Connecting to API...");
    
    // Attempt to connect to the API server
    if (client.connect("unohomewebapiappservice.azurewebsites.net", 80)) {
      Serial.println("Connected to API!");
    } else {
      Serial.println("Connection to API failed.");
      return; // Exit function if connection failed
    }
  }

  // Send the request if connected
    client.println("GET /api/Device/status/all HTTP/1.1");
    client.println("Host: unohomewebapiappservice.azurewebsites.net");
    client.println("Connection: keep-alive");  // Keep the connection alive
    client.println("User-Agent: ESP8266/1.0");
    client.println("Accept: */*");
    client.println();

    unsigned long startMillis = millis();
    String response = "";

    // Wait up to 1 second to read the response
    while (client.connected() && millis() - startMillis < 1000) {  
      while (client.available()) {  // Check if data is available
        char c = client.read();
        response += c;  // Append received character to response
      }
    }

    Serial.println("\nAPI Response:");
    Serial.println(response);

    parseResponse(response);
}



void parseResponse(String response) {
  int startIndex = response.indexOf("[");
  int endIndex = response.lastIndexOf("]");

  if (startIndex == -1 || endIndex == -1) {
    Serial.println("JSON array not found in the response.");
    return;
  }

  String jsonResponse = response.substring(startIndex, endIndex + 1);
  jsonResponse.replace("},{", "}@{");  // Use a separator to split each JSON object

  int separatorIndex = 0;
  while ((separatorIndex = jsonResponse.indexOf("@")) != -1) {
    String deviceStr = jsonResponse.substring(0, separatorIndex);
    jsonResponse = jsonResponse.substring(separatorIndex + 1);

    processDevice(deviceStr);
  }

  // Process the last device (or the only one if no separator was found)
  processDevice(jsonResponse);
}

void processDevice(String deviceStr) {
  String name = getValue(deviceStr, "name");
  String statusStr = getValue(deviceStr, "status");
  bool status = (statusStr == "true");

  handleDeviceStatus(name, status);
}

String getValue(String data, String key) {
  int keyIndex = data.indexOf("\"" + key + "\":");
  if (keyIndex == -1) return "";

  int startIndex = data.indexOf(":", keyIndex) + 1;
  int endIndex = data.indexOf(",", startIndex);
  if (endIndex == -1) endIndex = data.indexOf("}", startIndex);  // Adjust for last item

  String value = data.substring(startIndex, endIndex);
  value.trim();
  value.replace("\"", "");
  return value;
}

void handleDeviceStatus(String name, bool status) {

  //Fan device management
  if (name == "Fan") {
    //if fan status is on
      if (status) {
      digitalWrite(7, LOW);
      digitalWrite(fanPin, HIGH); // Turn fan on
      Serial.println("Fan turned ON");
      fanStatus = true;
    } else {
      //if fan status is off
      digitalWrite(7, HIGH);
      digitalWrite(fanPin, LOW); 
      Serial.println("Fan turned OFF");
      fanStatus = false;
      }



     //Yellow LED device management
  } else if (name == "Yellow LED") {
    if (!photocellActive) {
      //if the status is on
      if (status) {
        digitalWrite(yellowLEDPin, HIGH);  // Turn yellow LED on
        Serial.println("Yellow LED turned ON");
        yellowLEDStatus = true;
        //if status is off
      } else {
        digitalWrite(yellowLEDPin, LOW);   // Turn yellow LED off
        Serial.println("Yellow LED turned OFF");
        yellowLEDStatus = false;
      }
    }
  } 
  

  //white LED management
  if (name == "White LED") {
    //can only turn on/off if photocell is off
    if (!photocellActive) {
      if (status) {
        digitalWrite(whiteLEDPin, HIGH); 
        Serial.println("White LED turned ON");
        whiteLEDStatus = true;
    } else {
      digitalWrite(whiteLEDPin, LOW);   // Turn external LED OFF
      Serial.println("White LED turned OFF");
      whiteLEDStatus = false;
      }
    }


    //Door device management
  } else if (name == "Door Controller") {
    //if status is on
    if (status && !isDoorOpen) {
      // Open the window (move servo slowly to 90 degrees)
      for (int doorPos = 0; doorPos <= 90; doorPos++) { 
        servoDoor.write(doorPos);  // set position
      }
      isDoorOpen = true;
      Serial.println("Door Opened");
      doorStatus = true;
      //if status is off
    } else if (!status && isDoorOpen) {
      // Close the window (move servo slowly to 0 degrees)
      for (int doorPos = 90; doorPos >= 0; doorPos--) {
        servoDoor.write(doorPos);  // set position
      }
      isDoorOpen = false;
      Serial.println("Door Closed");
      doorStatus = false;
    }


    //window device management
  } else if (name == "Window Controller") {
    if (status && !isWindowOpen) {
      // Open the window (move servo slowly to 180 degrees)
      for (int windowPos = 0; windowPos <= 90; windowPos++) { 
        servoWindow.write(windowPos);  // set position
      }
      isWindowOpen = true;
      Serial.println("Window Opened");
      windowStatus = true;
      //if status is off
    } else if (!status && isWindowOpen) {
      // Close the window (move servo slowly to 0 degrees)
      for (int windowPos = 90; windowPos >= 0; windowPos--) {
        servoWindow.write(windowPos);  // set position
      }
      isWindowOpen = false;
      Serial.println("Window Closed");
      windowStatus = false;
    }
  }


  //motion sensor device management
  else if(name == "PIR Motion Sensor"){
    if(status){
      pinMode(pirSensorPin, INPUT);  // Set motion sensor as input
        
      // detect if there is motion
      int motionDetected = digitalRead(pirSensorPin);  
        
      // if motion was detected
      if (motionDetected == HIGH && !motionDetectedFlag) { 
        Serial.println("Motion Detected");

        //flag is so it doesnt constantly go off
        motionDetectedFlag = true;

        // buzzer makes a sound
        for (int i = 0; i < 80; i++) {
          digitalWrite(passiveBuzzerPin, HIGH);
          delay(1);
          digitalWrite(passiveBuzzerPin, LOW);
          delay(1);
        }
        for (int i = 0; i < 100; i++) {
          digitalWrite(passiveBuzzerPin, HIGH);
          delay(2);
          digitalWrite(passiveBuzzerPin, LOW);
          delay(2);
        }

        // after 2 seconds, resets the motion detection flag
        delay(2000);  

        motionDetectedFlag = false;
        Serial.println("Motion detection reset after 2 seconds");
      }
    }

    //photocell light sensor management
  }else if(name == "Photocell Sensor"){
    if(status){
      lightSensor();
    }
  }else if(name == "Panic Alarm"){
    if(status){
      activatePanicMode();
    }
  }
}


void loop() {

  // when clicking button 1, it activates the panic alarm
  if (digitalRead(button1Pin) == LOW && !panicActivated) {
    activatePanicMode();
  } 

  gasSensor();
  steamSensor();
  soilSensor();

  static unsigned long lastCheck = 0;
  if (millis() - lastCheck > 1000) {  // 1 seconds interval
    checkDeviceStatus();
    lastCheck = millis();
  }
  WiFiEspClient client = server.available();  // Check if a client has connected

  if (client) {  // If a client is available
    Serial.println("Client connected");
    client.println("Hello from ESP8266!");
    client.stop();
    Serial.println("Client disconnected");
  }
}

//method for the panic alarm
void activatePanicMode() {
  //flag to know if alarm is on or off
  panicActivated = true;
  
  // display "Panic Activated" on the screen
  lcd.clear();
  lcd.print("Panic Activated");


  // whiteLED flashes for 10 seconds
  unsigned long startTime = millis();  
  while (millis() - startTime < 10000) {  
    digitalWrite(whiteLEDPin, HIGH);  // Turn LED on
    delay(250);                     
    digitalWrite(whiteLEDPin, LOW);   // Turn LED off
    delay(250);     

    //buzer plays a sound for 10 seconds
    for (int i = 0; i < 80; i++) { 
      digitalWrite(passiveBuzzerPin, HIGH);
      delay(1);
      digitalWrite(passiveBuzzerPin, LOW);
      delay(1);
    }
    for (int i = 0; i < 100; i++) { 
      digitalWrite(passiveBuzzerPin, HIGH);
      delay(2);
      digitalWrite(passiveBuzzerPin, LOW);
      delay(2);
    }
            
  }

  lcd.clear();

  panicActivated = false;  // reset panic flag (is now deactivated)
}

void lightSensor() {
  int lightLevel = analogRead(photocellSensorPin);  // get the light status (dark or light)
  int threshold = 250;  // threshhold

  if (lightLevel < threshold) { // If it's dark
    digitalWrite(yellowLEDPin, HIGH);  // Turn on yellow LED
    digitalWrite(whiteLEDPin, LOW);   //turn White LED on
      digitalWrite(13, HIGH); 
    photocellActive = true;
  } else { // If there's no light
    digitalWrite(yellowLEDPin, LOW);   // Turn off yellow LED
    digitalWrite(whiteLEDPin, HIGH);  // Turn white led off
      digitalWrite(13, LOW); 
    photocellActive = false; 
  }
}
